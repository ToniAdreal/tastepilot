Verify a shared plan

  
Paste a plan JSON (for example one of the repo samples, or a
  plan someone shared with you). The server recomputes the evidence chain and
  the per-item checker verdict from the sealed record alone — the record's
  own verdict is never trusted. Edit any affinity in the pasted JSON and
  watch verification fail.

  
  

  
  

  
Exports are rendered by the server with the verification
  recomputed: a plan that fails its evidence check exports with a NOT
  VERIFIED banner, never a clean one. iCalendar export (from a generated
  plan above) needs at least one dated leg.

  
A shareable link stores the plan on this server under a
  content-addressed id; anyone opening it gets the plan back with its
  verification recomputed — the audit travels with the plan, no pasting.
  Links expire after 7 days. Links you create from this browser are
  owned by it (see “Your share links” below): only this browser can
  list or revoke them. Links created without an owner can be revoked
  by anyone holding them (the button below appears when you open one).

Your preference profile

  
Your swap choices teach the suggestion ranking —
  and that learning can persist. A persistent preference profile is
  stored on this server under this browser's owner token (only its
  hash is kept, exactly like your share links): save the lesson of
  the plan above — derived only from its sealed swap history, never
  from weights anyone types in — and later suggestions in any
  session apply it, reporting a stored profile was applied. A plan
  whose evidence chain does not verify teaches nothing.
